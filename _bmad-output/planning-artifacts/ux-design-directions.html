CaniFed Design Directions

CaniFed — Design Direction Showcase

Explore each screen to see how the Blue + Coral palette, Inter typography, and our UX patterns come together. Each view demonstrates a key user flow.

Direction A: Clean & Airy

Generous whitespace, card-based layout, prominent map thumbnails. Feels spacious and calm. Best for Patrick (low cognitive load).

  • Large cards with map previews
  • Generous spacing between elements
  • Prominent Navigate button (coral)
  • Minimal information per card

Direction B: Information-Dense

Compact cards, more events visible per scroll. Efficient for Julie (power user) and Perrine (admin scanning 30 events/month).

  • Smaller cards, more visible at once
  • RSVP counts inline
  • Draft badges visible in feed
  • Date grouping headers

Direction C: Map-Forward

Map takes center stage on event detail. Navigate button is the hero element. Optimized for the "Tap → Navigate → Arrive" flow.

  • Full-width map on event detail
  • Floating Navigate button
  • Location name prominent
  • Waze/Google Maps icon on button

Direction D: Dashboard-First (Admin)

Desktop admin view with sidebar navigation, data tables, and vaccine status at a glance. Marie's competition-day view.

  • Sidebar navigation with sections
  • Summary cards with counts
  • Color-coded status table
  • Filter/search prominent

Direction E: Community-Warm

Chat-forward design with member presence, avatars everywhere, "who's going" prominent. Feels like the club, not a tool.

  • Member avatars on event cards
  • Chat integrated with events
  • "Who's going" expanded by default
  • Club logo and identity prominent

Direction F: Guided Onboarding

Step-by-step club setup for Aude. Minimal fields, progress dots, encouraging copy. The "I did this myself" moment.

  • Single question per screen
  • Progress indicators
  • Friendly, encouraging tone
  • Skip options for optional fields
