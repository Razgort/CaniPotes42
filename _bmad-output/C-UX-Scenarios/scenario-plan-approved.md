## Suggested Scenarios

**01: Perrine's Club Setup** — Priority 1  
- **Pages:** Landing Page, Sign Up, Club Creation Flow, Club Settings, Member Invite Flow, Role Management  
- **Persona:** Perrine l'Organisatrice — set up club in 10 min, zero training  
- **User Value:** Functional club space with branding and invites in under 10 minutes  
- **Business Value:** One club onboarded → 30–150 members in pipeline toward 10 clubs / 12 mo  
- **Format:** Screen Flow  

**02: Perrine's Admin Day** — Priority 1  
- **Pages:** Event Creation/Edit, Member Directory, Vaccine Dashboard, Document Management (Admin), License Configuration, Payment History (Admin)  
- **Persona:** Perrine l'Organisatrice — events + GPS in two taps; single dashboard  
- **User Value:** Event published in ~90s; vaccines, docs, licenses visible in one place  
- **Business Value:** Admin self-service; quality events drive WAU and retention  
- **Format:** Mixed  

**03: Julie's Race Weekend** — Priority 1  
- **Pages:** Login, Club Home / Event Feed, Event Detail, Event Participation, Chat Channel List, Chat Conversation  
- **Persona:** Julie la Compétitrice — see/join events fast; GPS; no broken maps  
- **User Value:** One place for schedule, RSVP, carpool chat, navigation to meeting point  
- **Business Value:** In-app coordination replaces Facebook; proves daily value  
- **Format:** Mixed  

**04: Camille's Club Onboarding** — Priority 2  
- **Pages:** Email Invitation Accept, Member Profile, Dog Profile, Vaccine Record, Document Upload, My Documents (Member)  
- **Persona:** Invited new member (Camille) — complete profile, dogs, compliance docs  
- **User Value:** Membership active; dog + vaccines + documents ready to participate  
- **Business Value:** Network effects; validates admin adoption decision  
- **Format:** Screen Flow  

**05: Patrick's Simple Club Life** — Priority 2  
- **Pages:** Club Switcher, License Payment, User Settings  
- **Persona:** Patrick le Randonneur — notification → place → pay without friction  
- **User Value:** Sunday walk info in seconds; license paid; account under control  
- **Business Value:** Casual members retained; revenue; full-club adoption  
- **Format:** Screen Flow
