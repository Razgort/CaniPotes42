## Overview

**Page Purpose:** Vue par défaut du club : **liste chronologique des événements** à venir (puis passés repliés) ; accès RSVP rapide ; point d’entrée chat et création événement (admin).

**User Situation:** Julie ouvre l’app en semaine pour préparer le week-end.

**Success Criteria:** Voir prochains événements < 1 s après skeleton ; un tap vers détail.

**Entry Points:** Post-login ; switch club ; notification deep link (→ peut ouvrir 03.3 direct).

**Exit Points:** → [03.3](../03.3-event-detail/03.3-event-detail.md) · → création événement [02.1](../../02-perrine-admin-day/02.1-event-creation-edit/02.1-event-creation-edit.md) · → switcher [05.1](../../05-patrick-simple-club-life/05.1-club-switcher/05.1-club-switcher.md).

## Page Sections

### Section: Header club

**OBJECT ID:** `feed-header`

#### Nom club

**OBJECT ID:** `feed-club-title`

| Behavior | Truncate ; tap long = copy (non MVP) |

#### Switcher

**OBJECT ID:** `feed-club-switcher-trigger`

| FR aria | « Changer de club » |
| Behavior | Ouvre sheet [05.1](../../05-patrick-simple-club-life/05.1-club-switcher/05.1-club-switcher.md) |

#### Menu admin

**OBJECT ID:** `feed-admin-menu`

| Items | Créer un événement, Paramètres club (si permission) |

---

### Section: Filtre temporel

**OBJECT ID:** `feed-time-segment`

| Options | `upcoming` | `past` |
| FR | « À venir » | « Passés » |
| Default | upcoming |
| Behavior | Filtre liste locale ou refetch param |

---

### Section: Liste événements

**OBJECT ID:** `feed-event-list`

#### Card événement (répétée)

**OBJECT ID:** `feed-card` (instance par id)

| Contenu | Bloc date (jour + mois), titre, lieu texte 1 ligne |
| Thumb carte | Si `event.showMap` && coords → static map thumb 64x64 ou placeholder pin ; sinon icône lieu |
| Badge RSVP | `going` count ou statut utilisateur « Vous : Oui » |
| Tap | → 03.3 |

**OBJECT ID:** `feed-card-rsvp-chip`

| FR states | « Je viens » · « Peut-être » · « ? » non répondu |
| Behavior | Tap → stopPropagation → mini sheet RSVP (option) ou 03.4 |

---

### Section: Empty

**OBJECT ID:** `feed-empty`

| FR titre | « Aucun événement à venir » |
| FR body | « Quand votre club en publie, ils apparaîtront ici. » |
| Admin CTA | « Créer un événement » |
