---

## Overview

**Page Purpose:** Afficher l’**historique de messages** d’un canal et permettre l’**envoi en temps réel** ; support futur pièces jointes, mentions, modération.

**Success Criteria:** Scroll stable ; message envoyé visible ; reconnexion transparente.

## Object IDs

### Header

**OBJECT ID:** `chat-conv-header`

| Retour | → 03.5 |
| Titre | nom canal tronqué |
| Menu ⋮ | Infos canal, signalement (V2), mute (V2) |

### Liste messages

**OBJECT ID:** `chat-msg-list`

| Container | `overflow-y-auto` + `aria-live="polite"` pour nouveaux |

### Bulle

**OBJECT ID:** `chat-msg-bubble`

| Variantes | `incoming` | `outgoing` | `system` (join/leave) |
| Contenu | texte ; image V2 |

**OBJECT ID:** `chat-msg-time`

| Format | relatif < 24h sinon date courte |

### Composer

**OBJECT ID:** `chat-composer`

| Type | `textarea` auto-grow max 4 lignes |
| Placeholder FR | « Écrire un message… » |

**OBJECT ID:** `chat-attach` (V2)

**OBJECT ID:** `chat-send`

| FR | Icône envoyer + `aria-label` « Envoyer » |
| Disabled | si texte vide ou sending |

### Typing indicator

**OBJECT ID:** `chat-typing-indicator`

| FR | « Quelqu’un est en train d’écrire… » |

## Page States

| State | UI |
|-------|-----|
| Loading history | Skeleton bulles |
| Empty | « Aucun message — soyez le premier ! » |
| Sending | Optimistic bubble + état pending |
| Failed send | Icône retry sur bulle |
| Rate limited | Toast |

---

## Perf

- Pagination **cursor** `beforeMessageId` ; charger 30 par page.  
- Virtualisation liste si > 200 messages (V2).

---

## Accessibility

- Composer : Enter envoie, Shift+Enter newline (documenter).  
- Bulles : pas de `div` uniquement — rôle logique pour lecteur d’écran si besoin.
