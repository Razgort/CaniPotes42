---

## Overview

**Page Purpose:** Afficher le détail d’un événement : quand, où (texte), description, participants aperçu ; **carte interactive + navigation externe** si `event.showMap` et coordonnées valides ; sinon message explicite sans bouton navigation.

**Success Criteria:** Julie comprend lieu + horaire en < 10 s ; un tap ouvre Waze/Google si GPS.

**Exit Points:** ← Feed ; → [03.4](../03.4-event-participation/03.4-event-participation.md) ; → chat canal lié (V2).

## Page Sections

### Header

**OBJECT ID:** `event-detail-back`

---

### Bloc titre & meta

**OBJECT ID:** `event-detail-summary`

#### Titre

**OBJECT ID:** `event-detail-title`

| HTML | h1 |
| Source | `event.title` |

#### Plage horaire

**OBJECT ID:** `event-detail-schedule`

| Format FR | `jour mois · HH:mm – HH:mm` fuseau club ou user |

#### Lieu texte

**OBJECT ID:** `event-detail-location-text`

| Toujours affiché | `event.locationText` |

#### Bandeau annulé

**OBJECT ID:** `event-detail-cancelled-banner`

| Si | `event.status === CANCELLED` |
| FR | « Cet événement est annulé. » |

---

### Carte GPS (conditionnelle)

**OBJECT ID:** `event-detail-map-section`

| Visible si | `event.showMap === true` && `lat && lng` |

#### Carte

**OBJECT ID:** `event-detail-map`

| Component | Lecteur seul + pin (pas d’édition) |

#### Pas de GPS (showMap false OU coords null)

**OBJECT ID:** `event-detail-no-gps-notice`

| FR | « Pas de point GPS pour cet événement — le lieu indiqué ci-dessus fait foi. » |
| Style | `bg-primary-light` ou `border` info |

---

### Actions principales

**OBJECT ID:** `event-detail-actions`

#### S'y rendre

| Visible | `showMap && coords` |
| FR | « S’y rendre » |
| Behavior | `geo:` ou choix modal Waze / Google Maps / Apple Maps |
| Disabled + tooltip | Si pas coords |

#### Participer

**OBJECT ID:** `event-detail-rsvp-cta`

| FR | « Participer » ou statut actuel « Vous participez » |
