## Overview

**Page Purpose:** Lister les **canaux de discussion** du club (général, par événement, annonces) avec **aperçu du dernier message**, **horodatage relatif** et **compteur non-lus** ; accéder à [03.6](../03.6-chat-conversation/03.6-chat-conversation.md).

**Success Criteria:** Julie repère le canal carpool en < 5 s ; badge unread fiable.

## Object IDs

### Liste

**OBJECT ID:** `chat-channel-list`

| Role | `list` |

### Row canal

**OBJECT ID:** `chat-channel-row`

| Tap | → `/clubs/:clubId/chat/:channelId` |
| Contenu | Icône/type canal, nom, preview dernière ligne, time, badge |

**OBJECT ID:** `chat-channel-name` · `chat-channel-preview` · `chat-channel-time` · `chat-channel-unread-badge`

### Empty

**OBJECT ID:** `chat-channel-empty`

| FR | « Aucune discussion pour ce club. » |
| Admin | « Créer un canal » V2 |

### Bannière connexion

**OBJECT ID:** `chat-connection-banner`

| FR offline | « Hors ligne — les messages s’afficheront à la reconnexion. » |
| Reconnecting | « Reconnexion… » |
