## Overview

**Page Purpose:** Enregistrer la **réponse de participation** (Je viens / Peut-être / Je ne viens pas) et afficher la **liste des participants** avec statut ; préparer lien vers chat événement si canal existe.

**Success Criteria:** Choix persisté < 500 ms perçu ; compteurs mis à jour ; cohérence avec 03.2 cards et 03.3 CTA.

**Exit Points:** Fermeture sheet → 03.3 ; retour navigateur → 03.3 ou feed.

## Object IDs & contenu

### Groupe RSVP

**OBJECT ID:** `rsvp-segment`

| Option | value API | FR |
|--------|-----------|-----|
| Going | `GOING` | « Je viens » |
| Maybe | `MAYBE` | « Peut-être » |
| Declined | `DECLINED` | « Je ne viens pas » |

**OBJECT ID:** `rsvp-option-going` · `rsvp-option-maybe` · `rsvp-option-declined`

| Behavior | `PATCH` immédiat au tap (optimistic) ou bouton « Enregistrer » secondaire — **recommandation** : sauvegarde immédiate + undo toast 5s |

### Compteurs

**OBJECT ID:** `rsvp-counts-summary`

| FR pattern | « {{going}} oui · {{maybe}} peut-être · {{declined}} non » |

### Liste participants

**OBJECT ID:** `rsvp-participant-list`

| Row | `rsvp-participant-row` — avatar, displayName, badge statut |
| Privacy MVP | Noms visibles tous membres club (option masquer V2) |

### Chat

**OBJECT ID:** `rsvp-open-chat-cta`

| Visible si | `channelId` lié à l’événement |
| FR | « Ouvrir le chat de l’événement » |

## Page States
