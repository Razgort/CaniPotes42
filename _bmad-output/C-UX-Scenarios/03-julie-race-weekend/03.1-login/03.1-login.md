## Overview

**Page Purpose:** Authentifier l’utilisateur par **email + mot de passe** ; rediriger vers la **page demandée** (`redirect` / `location.state.from`) ou vers **l’accueil** / **setup club** si aucun club actif.

**Success Criteria:** Session JWT/contexte `AuthContext` rempli ; toast succès ; navigation < 1 s.

**Entry Points:** Lien depuis landing, sign-up, session expirée, deep link protégé.

**Exit Points:** → `/` (home) · → `/club-setup` si `!activeClub` · → URL `from` si présente · → mot de passe oublié (V2).

---

## Implémentation actuelle (référence code)

`LoginForm.tsx` : `react-hook-form` + `loginSchema` (`@org/types`) ; `useLogin` mutation ; `toast.success` / `toast.error` ; navigation :

- pas de `activeClub` → `/club-setup`
- sinon `location.state.from` → cette URL
- sinon → `/`

Lien inscription : **`/register`** (aligner specs 01.2 si routes unifiées `/auth/sign-up`).
