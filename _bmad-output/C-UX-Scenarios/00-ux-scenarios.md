## Scenarios

### [01: Perrine's Club Setup](01-perrine-sets-up-club/01-perrine-sets-up-club.md)

**Persona:** Perrine l'Organisatrice — 10 min setup, zero training  
**Pages:** Landing Page, Sign Up, Club Creation Flow, Club Settings, Member Invite Flow, Role Management  
**User Value:** Club live with invites in under 10 minutes  
**Business Value:** One onboarded club → 30–150 members toward adoption goals  

---

### [02: Perrine's Admin Day](02-perrine-admin-day/02-perrine-admin-day.md)

**Persona:** Perrine l'Organisatrice — GPS events + single dashboard  
**Pages:** Event Creation/Edit, Member Directory, Vaccine Dashboard (Admin), Document Management (Admin), License Configuration (Admin), Payment History (Admin)  
**User Value:** Published event + compliance overview without leaving the app  
**Business Value:** Zero broken maps narrative; admin self-service  

---

### [03: Julie's Race Weekend](03-julie-race-weekend/03-julie-race-weekend.md)

**Persona:** Julie la Compétitrice — fast RSVP + chat + GPS  
**Pages:** Login, Club Home / Event Feed, Event Detail, Event Participation, Chat Channel List, Chat Conversation  
**User Value:** Weekend logistics and navigation from one place  
**Business Value:** WAU and in-app coordination replacing Facebook  

---

### [04: Camille's Club Onboarding](04-new-member-joins/04-new-member-joins.md)

**Persona:** Camille (invited new member) — profile, dog, compliance  
**Pages:** Email Invitation Accept, Member Profile, Dog Profile, Vaccine Record, Document Upload, My Documents (Member)  
**User Value:** Ready to participate with documents on file  
**Business Value:** Completes admin adoption loop with real member data  

---

### [05: Patrick's Simple Club Life](05-patrick-simple-club-life/05-patrick-simple-club-life.md)

**Persona:** Patrick le Randonneur — notify → pay → trust  
**Pages:** Club Switcher, License Payment, User Settings  
**User Value:** Minimal path for Sunday walk context + payment + account control  
**Business Value:** Retains casual cohort; satisfies “Patrick Test”
