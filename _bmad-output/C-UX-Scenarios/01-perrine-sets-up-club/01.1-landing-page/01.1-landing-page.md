## Overview

**Page Purpose:** Convaincre une présidente / un admin de club canin que CaniFed est crédible, moderne et gratuit ; déclencher l’inscription avec un seul CTA clair.

**User Situation:** Soirée après une AG ou un événement régional ; lien reçu par message ; peu de patience pour le jargon SaaS.

**Success Criteria:** Clic sur le CTA principal vers l’écran d’inscription ; optionnellement scroll jusqu’à la promesse « événements + GPS qui marchent ».

**Entry Points:**

- Lien profond `https://…/` depuis messagerie / réseau social  
- SEO organique (secondaire MVP)  
- QR code flyer club (post-MVP)

**Exit Points:**

- CTA primaire → **Sign Up** (`/auth/sign-up` ou équivalent)  
- Lien secondaire « Se connecter » → **Login**  
- Liens pied de page → **Mentions légales**, **Confidentialité** (routes à définir)

## Layout Structure

Page marketing **scrollable** en une colonne sur mobile ; sur desktop, contenu centré avec `max-width` 1200px, marges latérales généreuses. Pas de barre d’app club (header produit minimal ou header marketing dédié).

```
+---------------------------+
| Top bar (logo + actions)  |
+---------------------------+
| Hero (H1 + sous-texte)    |
| [ CTA primaire ]          |
| [ lien connexion discret] |
+---------------------------+
| ↕ section gap             |
| 3 piliers (cartes/icônes) |
+---------------------------+
| ↕ section gap             |
| Bandeau confiance / preuve|
+---------------------------+
| Footer (liens légaux)     |
+---------------------------+
| (mobile) CTA sticky opt.  |
+---------------------------+
```

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | SSR/CSR OK | Contenu complet | Tous les liens actifs |
| Loading | CSR transition | Skeleton léger hero + barres piliers _(optionnel si SSR)_ | Aucune |
| Error | Échec chargement bundle | Message `.text-body` + bouton « Réessayer » | Retry reload |
| Offline (PWA) | Service worker | Bannière discrète « Hors ligne — contenu partiel » | CTA désactivés sauf cache |

## Accessibility

- Un seul `h1` (hero).  
- Ordre tab : logo → connexion → CTA → piliers → footer.  
- Contraste texte sur fond : respect WCAG AA (tokens `foreground` / `background`).  
- CTA : taille zone tactile min. 44×44px.  

---

## Technical Notes

- **i18n :** MVP `lang=fr` ; clés listées pour future locale `en`.  
- **Layout :** La landing peut **ne pas** utiliser `AppShell` club (header 56px + bottom tabs) pour éviter la confusion « déjà dans un club » — préférer header marketing minimal.  
- **Perf :** LCP = headline + CTA ; pas de carrousel auto-play.
