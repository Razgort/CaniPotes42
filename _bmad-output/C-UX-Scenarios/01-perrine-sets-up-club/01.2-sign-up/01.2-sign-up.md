## Overview

**Page Purpose:** Créer un compte CaniFed (email + mot de passe) avec consentement RGPD explicite ; enchaîner vers création de club ou URL de retour.

**User Situation:** Arrivée depuis la landing ou un lien partagé ; peu de patience pour les formulaires longs.

**Success Criteria:** Compte créé sans erreur ; cookie/session établie ; redirection < 2 s après succès.

**Entry Points:** CTA landing ; lien direct marketing.

**Exit Points:** → `/onboarding/club/create` (intent club) ; → `redirect` si valide ; → Login.

## Interactions

- Submit : validation client → POST ; erreur 409 email pris → message sous champ email.  
- Succès : toast optionnel bref → redirect.
