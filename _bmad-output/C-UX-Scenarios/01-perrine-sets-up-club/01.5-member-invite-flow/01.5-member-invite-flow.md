## Overview

**Page Purpose:** Envoyer des **invitations par e-mail** pour rejoindre le club ; choisir le **rôle initial** (Membre par défaut, Admin si autorisé) ; message personnalisé optionnel ; feedback sur succès / échecs partiels.

**Success Criteria:** E-mails partis (ou file d’attente) ; invitations visibles en « En attente » ; pas d’email invalide silencieux.

**Exit Points:** → [01.6](../01.6-role-management/01.6-role-management.md) · → liste invitations (même page section ou onglet)

## Object IDs

### Zone e-mails

**OBJECT ID:** `invite-emails-textarea`

| FR label | « Adresses e-mail » |
| FR placeholder | « une@adresse.fr, autre@… » ou une par ligne |
| Parser | split `,` `;` `\n` ; trim ; lowercase ; dédoublonner |
| Max batch | **50** par requête (config serveur) |

**OBJECT ID:** `invite-email-count`

| Affiche | « {{n}} invitation(s) » après parse |

### Rôle

**OBJECT ID:** `invite-role-select`

| Options | `MEMBER` (défaut) ; `ADMIN` visible seulement si `canInviteAdmin` (OWNER ou policy) |
| FR | « Membre » · « Administrateur » |

### Message

**OBJECT ID:** `invite-personal-message`

| Max | 500 car. |
| FR label | « Message personnel (optionnel) » |

### Aperçu

**OBJECT ID:** `invite-email-preview`

| Contenu | Objet type « Invitation au club {{clubName}} » + 2 lignes corps |

### Submit

**OBJECT ID:** `invite-submit`

| FR | « Envoyer les invitations » |
| Disabled | si 0 email valide ou loading |

### Liste pending

**OBJECT ID:** `invite-pending-list`

| Row | email, statut, date ; action « Renvoyer » / « Révoquer » V2 |
