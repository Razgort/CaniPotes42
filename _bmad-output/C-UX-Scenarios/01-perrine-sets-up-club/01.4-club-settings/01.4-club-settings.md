## Overview

**Page Purpose:** Modifier les **paramètres du club** : identité, logo, fédération, description, **`defaultEventShowMap`** (aligné [02.1](../../02-perrine-admin-day/02.1-event-creation-edit/02.1-event-creation-edit.md) et [01.3](../01.3-club-creation-flow/01.3-club-creation-flow.md)), fuseau horaire optionnel ; accès refusé aux **MEMBER**.

**Success Criteria:** Sauvegarde toast ; feed et création d’événements reflètent le nouveau défaut carte.

## Object IDs

**OBJECT ID:** `club-settings-name` — required  
**OBJECT ID:** `club-settings-slug` — read-only après création MVP ou édition OWNER avec avertissement  
**OBJECT ID:** `club-settings-description` — max 500  
**OBJECT ID:** `club-settings-logo` — upload comme 01.3  
**OBJECT ID:** `club-settings-federation` — enum + custom si Other  
**OBJECT ID:** `club-settings-default-map`

| FR label | « Afficher la carte GPS par défaut sur les nouveaux événements » |
| FR help | « Désactivable sur chaque événement (ex. lieu fixe CNEAC). » |
| Persist | `club.settings.defaultEventShowMap` |

**OBJECT ID:** `club-settings-timezone` — `Europe/Paris` défaut  
**OBJECT ID:** `club-settings-save` — FR « Enregistrer les modifications »
