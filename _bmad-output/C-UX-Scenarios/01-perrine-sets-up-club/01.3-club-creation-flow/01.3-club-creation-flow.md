## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | Perrine's Club Setup |
| **Page Number** | 01.3 |
| **Platform** | Mobile-first |
| **Visibility** | Authenticated |
| **Route** | `/onboarding/club/create` (query `?step=1|2|3` optionnel) |

---

## Overview

**Page Purpose:** Créer le **tenant club** en 3 étapes linéaires : identité → fédération → finition (description, logo, défaut carte GPS aligné [02.1](../../02-perrine-admin-day/02.1-event-creation-edit/02.1-event-creation-edit.md)).

**Success Criteria:** Club persisté ; utilisateur **OWNER** ; redirection vers Club Settings ou invite.

**Exit Points:** → [01.4](../01.4-club-settings/01.4-club-settings.md) · abandon → dialog confirmation.

## Step 1 — Identité

**OBJECT ID:** `club-wizard-step-1`

#### Nom du club

**OBJECT ID:** `club-create-name`

| FR label | « Nom du club » |
| EN | « Club name » |
| Validation | required, 2–80 chars |
| Behavior | on blur → preview slug |

#### Slug (URL)

**OBJECT ID:** `club-create-slug`

| FR label | « Adresse web du club » |
| Help FR | « canifed.fr/clubs/votre-slug — lettres, chiffres, tirets » |
| Validation | `^[a-z0-9]+(?:-[a-z0-9]+)*$`, min 3, max 48 ; async disponibilité |
| États | checking… ✓ disponible / ✗ pris |

#### Localisation optionnelle

**OBJECT ID:** `club-create-city`

| FR | « Ville ou région (optionnel) » |

**OBJECT ID:** `club-wizard-next-1` — FR « Suivant »

---

## Step 2 — Fédération

**OBJECT ID:** `club-wizard-step-2`

#### Select fédération

**OBJECT ID:** `club-create-federation`

| Options valeur | `FFSLC`, `CNEAC`, `INDEPENDENT`, `OTHER` |
| FR labels | FFSLC · CNEAC · Indépendant · Autre |
| Si OTHER | show `club-create-federation-custom` text input |

**OBJECT ID:** `club-wizard-back-2` · `club-wizard-next-2`

---

## Step 3 — Finition

**OBJECT ID:** `club-wizard-step-3`

#### Description

**OBJECT ID:** `club-create-description`

| FR | « Présentation courte du club » |
| Max | 500 chars |

#### Logo

**OBJECT ID:** `club-create-logo`

| Accept | image/*, max 2 Mo |
| UI | Carré preview 96px, bouton « Changer » |
| États | upload progress, erreur type/taille |

#### Toggle défaut carte événements

**OBJECT ID:** `club-create-default-map-toggle`

| FR label | « Afficher la carte GPS par défaut sur les nouveaux événements » |
| FR help | « Vous pourrez désactiver la carte sur chaque événement (ex. local fixe CNEAC). » |
| Default | ON |
| Persist | `club.settings.defaultEventShowMap` |

**OBJECT ID:** `club-wizard-back-3` · `club-wizard-submit` — FR « Créer mon club »
