## Overview

**Page Purpose:** Gérer **rôles** et **appartenance** : MEMBER ↔ ADMIN ; **un seul OWNER** — transfert explicite ; retirer du club (avec garde-fous).

**Success Criteria:** Jamais zéro OWNER ; jamais dernier ADMIN supprimé sans confirmation ; actions traçables (audit V2).

## Règles métier (UI)

| Règle | Comportement |
|-------|--------------|
| 1 OWNER | Impossible rétrograder OWNER sans transfert |
| ≥1 ADMIN ou OWNER | Bloquer retrait si laisserait 0 admin (sauf OWNER seul) |
| Self-remove | Autorisé seulement si autre OWNER (impossible) ou quitter = démission avec autre admin |
