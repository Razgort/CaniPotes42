## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | Camille's Club Onboarding |
| **Page Number** | 04.2 |
| **Route** | `/clubs/:clubId/me/profile` |
| **Visibility** | Auth, MEMBER (édition **soi uniquement**) |
| **Platform** | Mobile-first |

---

## Overview

**Page Purpose:** Permettre au membre de renseigner son **profil visible dans le club** : prénom, nom, téléphone, photo, champs optionnels (adresse) selon **politique club** ; distinct du compte global [05.3](../../05-patrick-simple-club-life/05.3-user-settings/05.3-user-settings.md).

**Success Criteria:** Données persistées ; annuaire admin ([02.2](../../02-perrine-admin-day/02.2-member-directory/02.2-member-directory.md)) à jour.

## Object IDs

**OBJECT ID:** `profile-photo`

| Upload | crop circulaire, max 2 Mo, formats image |
| FR bouton | « Changer la photo » |

**OBJECT ID:** `profile-firstname` — required  
**OBJECT ID:** `profile-lastname` — required  
**OBJECT ID:** `profile-phone` — `tel` optional, validation E.164 light  
**OBJECT ID:** `profile-address-line1` · `profile-address-city` · `profile-address-zip` — optional, visible si `club.requireMemberAddress`

**OBJECT ID:** `profile-save`

| FR | « Enregistrer » |
| Toast succès | « Profil mis à jour » |
