# 04.1 — Email Invitation Accept

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | Camille's Club Onboarding |
| **Page Number** | 04.1 |
| **Platform** | Mobile-first |
| **Visibility** | Public (token) + auth context variable |
| **Route** | `/invite/:token` |

---

## Overview

**Page Purpose:** Consommer un **lien d’invitation** signé : afficher le club cible ; créer compte + rattachement **ou** joindre le club au compte existant après login.

**User Situation:** Camille ouvre l’email sur mobile le soir.

**Success Criteria:** Adhésion club active ; session authentifiée ; redirection vers profil membre [04.2](../04.2-member-profile/04.2-member-profile.md).

**Entry Points:** Unique URL email (token JWT ou opaque id).

**Exit Points:** → 04.2 · → login si existant non connecté · erreur token.

## Variantes — Utilisateur existant (email token match compte)

**OBJECT ID:** `invite-flow-existing`

| Si session active + email match | CTA direct **Accepter** |

**OBJECT ID:** `invite-submit-join`

| FR | « Rejoindre le club » |

| Si pas de session | Lien **« Se connecter »** → `/auth/login?redirect=/invite/:token`** |
