---

## Overview

**Page Purpose:** Téléverser un **fichier** (PDF, JPEG, PNG, WEBP) et le rattacher à **l’utilisateur** ou à **un de ses chiens**, avec **type de document** et **date d’expiration** optionnelle pour suivi admin ([02.4](../../02-perrine-admin-day/02.4-document-management-admin/02.4-document-management-admin.md)).

**Success Criteria:** Upload complété ; document visible dans [04.6](../04.6-my-documents-member/04.6-my-documents-member.md) ; toast succès.

## Object IDs

### Zone fichier

**OBJECT ID:** `doc-upload-zone`

| Accept | `.pdf,.jpg,.jpeg,.png,.webp` + MIME check |
| Max size | 10 Mo (config serveur) |
| Desktop | drag-drop + click |
| Mobile | `<input type="file" capture="environment">` option photo |

**OBJECT ID:** `doc-upload-file-preview`

| Affiche | nom, taille, bouton retirer |

### Cible

**OBJECT ID:** `doc-upload-target`

| Type | `radio` ou `select` |
| Options | `SELF`, `DOG:{id}` |
| FR labels | « Moi » · « {{dogName}} » |

### Type document

**OBJECT ID:** `doc-upload-type`

| Source | Enum club ou liste globale : CERTIFICATE_VACCINE, INSURANCE, OTHER… |
| FR | Libellés métier |

### Expiration

**OBJECT ID:** `doc-upload-expiry`

| Type | `date` |
| FR label | « Date d’expiration (optionnel) » |

### Submit

**OBJECT ID:** `doc-upload-submit`

| FR | « Envoyer » |
| Disabled | si pas fichier ou type manquant |

### Progression

**OBJECT ID:** `doc-upload-progress`

| Barre | 0–100 % pendant `multipart/form-data` ou signed URL flow |

## Page States

| State | UI |
|-------|-----|
| Idle | Zone vide |
| File selected | Preview + enable submit |
| Uploading | Progress + bouton disabled |
| Success | Toast + redirect 04.6 ou rester |
| Error type | « Format non accepté » |
| Error size | « Fichier trop volumineux (max 10 Mo) » |
| Error server | Toast générique |

---

## Validation client

- Fichier requis avant submit.  
- Type requis.  
- Date expiration ≥ aujourd’hui si renseignée.

---

## Accessibility

- Zone upload : `role="button"` + `tabindex=0` + Enter pour ouvrir file picker.  
- Annoncer fin upload `aria-live="polite"`.
