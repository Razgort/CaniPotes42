---

## Overview

**Page Purpose:** Afficher l’**échéance licence** du membre pour le club actif, le **montant** et le **type** configurés par l’admin ([02.5](../../02-perrine-admin-day/02.5-license-configuration-admin/02.5-license-configuration-admin.md)) ; lancer **Stripe Checkout** ; gérer retour success/cancel.

**Success Criteria:** Patrick paie en peu d’étapes ; reçu accessible ; statut licence à jour dans l’app.

## Page Sections

### Header

**OBJECT ID:** `lic-pay-header`

| FR titre | « Paiement de licence » |

### État « déjà payé »

**OBJECT ID:** `lic-pay-status-paid`

| Visible si | `membership.licenseStatus === ACTIVE` et échéance future |
| FR | « Votre licence est à jour jusqu’au {{date}}. » |
| CTA secondaire | « Voir le reçu » → URL Stripe hosted ou PDF |

### Récapitulatif

**OBJECT ID:** `lic-pay-summary`

| Lignes | Type licence, montant TTC, devise EUR, saison/année si défini |
| Source | GET `me/license-summary?clubId=` |

### CTA Checkout

**OBJECT ID:** `lic-pay-cta-stripe`

| FR | « Payer maintenant » |
| Behavior | POST create Checkout Session → `redirect` Stripe |
| Disabled si | déjà payé ou montant 0 (club gratuit) |

### Copy confiance

**OBJECT ID:** `lic-pay-trust-copy`

| FR | « Paiement sécurisé par Stripe. CaniFed ne stocke pas votre numéro de carte. » |

### Retour success

**OBJECT ID:** `lic-pay-success-toast`

| Query | `?payment=success` — toast + invalidate queries |

### Retour cancel

**OBJECT ID:** `lic-pay-cancel-banner`

| FR | « Paiement annulé. Aucun montant débité. » |

### Reçu

**OBJECT ID:** `lic-pay-receipt-link`

| Post-success | Lien `hosted_invoice_url` ou page reçu app |
