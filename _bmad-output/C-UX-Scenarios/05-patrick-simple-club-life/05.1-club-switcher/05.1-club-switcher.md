## Page Metadata

| Property | Value |
|----------|-------|

| **Surface** | **Sheet** / **Modal** (bottom sur mobile) depuis header [03.2](../../03-julie-race-weekend/03.2-club-home-event-feed/03.2-club-home-event-feed.md) · route pleine option `/me/clubs` |

---

## Overview

**Page Purpose:** Changer le **`activeClub`** en **≤ 2 interactions** (ouvrir + sélectionner) ; afficher **logo + nom** ; indiquer le club **actuel** ; respecter deep link notification (pré-sélection / auto-switch si `clubId` query match).

**Success Criteria:** Patrick ne se trompe pas de club pour la randonnée ; `AuthContext` + queries TanStack **invalidées** après switch.

## Object IDs

**OBJECT ID:** `switcher-sheet`

| `role` | `dialog` `aria-modal="true"` `aria-labelledby` |

**OBJECT ID:** `switcher-close`

| FR | « Fermer » ou X avec `aria-label` |

**OBJECT ID:** `switcher-list`

**OBJECT ID:** `switcher-row`

| Contenu | Logo 40px, nom club, checkmark si actif |
| Tap | `switchClub(clubId)` → loading row → success fermeture sheet + navigate `/clubs/:clubId` ou refresh context |

**OBJECT ID:** `switcher-active-indicator`

| Visuel | check + fond `primary-light` sur ligne active |

**OBJECT ID:** `switcher-single-club-message`

| Si `memberships.length === 1` | Masquer sheet **ou** afficher « Vous n’avez qu’un club » + fermer — **recommandation** : ne pas afficher l’entrée menu « Changer » si 1 club |
