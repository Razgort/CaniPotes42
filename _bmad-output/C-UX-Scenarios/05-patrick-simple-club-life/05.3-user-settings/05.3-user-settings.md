## Object IDs

### Email

**OBJECT ID:** `user-email-display`

| Affichage | email masqué partiel option `pat***@domain.fr` |
| CTA | `user-email-change` → flow reverify (email lien) V1 simplifié : formulaire + password confirm |

### Mot de passe

**OBJECT ID:** `user-password-change-trigger`

| Ouvre | sheet / page `user-password-change` avec ancien + nouveau + confirm |

### Export RGPD

**OBJECT ID:** `user-export-data`

| FR | « Télécharger mes données » |
| Behavior | POST async → email avec lien zip sous 72h (copy légale) ou download immédiat si petit |

### Suppression compte

**OBJECT ID:** `user-delete-account`

| FR | « Supprimer définitivement mon compte » |
| Ouvre | modale `user-delete-modal` |

**OBJECT ID:** `user-delete-modal`

| Corps FR | « Cette action est irréversible. Vous perdrez l’accès à tous vos clubs. Les clubs pourront conserver des données légales anonymisées. » |
| Input confirm | taper `SUPPRIMER` |
| CTA | `user-delete-confirm` rouge |
