# 02.5 — License Configuration (Admin)

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | Perrine's Admin Day |
| **Page Number** | 02.5 |
| **Route** | `/clubs/:clubId/settings/licenses` |
| **Visibility** | **OWNER** ou **ADMIN** avec permission `billing.manage` |
| **Platform** | Mobile-first |

---

## Overview

**Page Purpose:** Configurer les **types de licence** facturés aux membres : libellé, **montant TTC** (EUR), description affichée côté [05.2](../../../05-patrick-simple-club-life/05.2-license-payment/05.2-license-payment.md), période / saison ; activer/désactiver ; statut **connexion Stripe** (MVP : placeholder ou état binaire).

**Success Criteria:** Membres voient le bon montant au paiement ; aucun montant modifiable côté client sans refetch serveur.

## Object IDs

**OBJECT ID:** `lic-config-stripe-status`

| États FR | « Connecté » · « Action requise » · « Non configuré » |
| CTA | Lien dashboard Stripe externe (si Connect) |

**OBJECT ID:** `lic-config-type-list`

**OBJECT ID:** `lic-config-row`

| Affiche | libellé, montant formaté `45,00 €`, badge Actif/Inactif |
| Actions | Éditer, Désactiver (soft) |

**OBJECT ID:** `lic-config-add`

| FR | « Ajouter un type de licence » |

### Formulaire type (modal/sheet)

**OBJECT ID:** `lic-config-form-label` — required, max 80  
**OBJECT ID:** `lic-config-form-amount` — number, min 0.01, step 0.01, **devise EUR**  
**OBJECT ID:** `lic-config-form-description` — textarea, affichée au membre avant paiement, max 500  
**OBJECT ID:** `lic-config-form-active` — switch  
**OBJECT ID:** `lic-config-form-season` — optionnel texte ex. « 2025/2026 »  
**OBJECT ID:** `lic-config-save`
