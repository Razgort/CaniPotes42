## Overview

**Page Purpose:** Vue **opérationnelle** de tous les membres : identité, rôle, statut **invitation / actif**, indicateur **licence** (payée / manquante) ; accès rapide vers fiche synthèse (drawer ou page) sans éditer tout le profil membre (édition = [04.2](../../../04-new-member-joins/04.2-member-profile/04.2-member-profile.md) côté membre ou futur admin-edit).

**Success Criteria:** Perrine repère qui n’a pas payé ou qui est « en attente » en un coup d’œil.
