## Overview

**Page Purpose:** Tableau de bord **agrégé par chien** (tous les membres du club) : statut vaccinal **🟢 OK · 🟠 bientôt · 🔴 manquant / expiré** ; filtres ; lien vers saisie membre [04.4](../../../04-new-member-joins/04.4-vaccine-record/04.4-vaccine-record.md) ou contact.

**Success Criteria:** Perrine priorise les relances sans ouvrir chaque dossier.

## Object IDs

**OBJECT ID:** `vax-dash-summary-ok` · `vax-dash-summary-warn` · `vax-dash-summary-bad`

| FR labels | « À jour » · « À renouveler » · « Manquant / expiré » |

**OBJECT ID:** `vax-dash-filter-status`

| Options | Tous · OK · Warning · Critical |

**OBJECT ID:** `vax-dash-search`

| Placeholder | « Chien ou propriétaire… » |

**OBJECT ID:** `vax-dash-row`

| Colonnes visuelles | Avatar chien optionnel, nom chien, membre, statut badge, jours avant échéance |
| Tap | → drawer : détail vaccins + lien « Contacter » mailto / « Ouvrir dossier » deep link 04.4 |

**OBJECT ID:** `vax-dash-status-icon`

| Accessibilité | Texte + icône, pas couleur seule (`aria-label` statut)

**OBJECT ID:** `vax-dash-export` (V2)
