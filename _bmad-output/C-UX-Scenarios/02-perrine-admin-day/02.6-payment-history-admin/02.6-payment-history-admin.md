# 02.6 — Payment History (Admin)

## Page Metadata

| Property | Value |
|----------|-------|
| **Scenario** | Perrine's Admin Day |
| **Page Number** | 02.6 |
| **Route** | `/clubs/:clubId/payments` |
| **Visibility** | **ADMIN+** (souvent restreindre montants à OWNER — policy) |
| **Platform** | Mobile-first ; cartes empilées |

---

## Overview

**Page Purpose:** Historique des **paiements de licence** encaissés pour le club : membre, montant, date, **statut** (réussi, remboursé, échoué, en attente), référence Stripe ; filtres ; lien **reçu**.

**Success Criteria:** Réconciliation simple avec Stripe ; export CSV V2.

| Type | `date` |

| Select searchable |

| Options | Tous · Réussi · Remboursé · Échoué · En attente |

**OBJECT ID:** `pay-hist-list`

**OBJECT ID:** `pay-hist-row`

| Contenu | displayName membre (lien 02.2), montant TTC, date locale, statut badge, `paymentIntentId` tronqué copiable |
| Expand | Détails : type licence, frais Stripe nets (si exposé API) |
