## Overview

**Page Purpose:** Créer ou modifier une séance : lieu (texte obligatoire ; **carte GPS optionnelle par événement**), horaires, description, capacité ; enregistrer avec un **toggle Brouillon / Publié** ; à la **première publication** (MVP), afficher une **modale de confirmation**.

**User Situation:** Lundi matin, admin connecté, club déjà sélectionné — préparation de la séance de la semaine.

**Success Criteria:** Données persistées ; si carte activée, pin cohérent ; si carte désactivée (ex. CNEAC, lieu fixe), libellé lieu suffisant pour les membres ; passage à « Publié » avec confirmation explicite.

**Entry Points:**

- Liste / feed événements → « Créer un événement »  
- Fiche événement → « Modifier »  
- Deep link admin (bookmark interne)

**Exit Points:**

- Après enregistrement réussi → retour liste événements ou **Member Directory** (scénario 02) selon navigation produit  
- Annuler avec changements non sauvegardés → garde-fou (voir États)

## Layout Structure

### Mobile — carte **activée** (`showMapForEvent === true`)

Ordre vertical :

1. Header (retour, titre, menu optionnel)  
2. **Bloc carte** (hauteur min ~220px, plein écran possible)  
3. **Toggle** « Afficher la carte GPS pour cet événement » (**ON**)  
4. Formulaire (titre, date/heure, lieu texte, description, capacité)  
5. **Toggle** statut **Brouillon | Publié**  
6. Barre fixe : bouton primaire **« Enregistrer »**

### Mobile — carte **désactivée**

1. Header  
2. **Toggle** « Afficher la carte GPS pour cet événement » (**OFF**) — placé **au-dessus** du champ lieu pour expliquer le contexte  
3. Formulaire (pas de bloc carte)  
4. Toggle Brouillon | Publié  
5. **Enregistrer**

### Desktop (≥1024px)

- Deux colonnes si carte ON : formulaire ~40 % | carte sticky ~60 %  
- Une colonne si carte OFF : formulaire centré `max-width` ~640px  

```
[ Carte ON — mobile ]
+------------------+
| Header           |
+------------------+
| Map + pin        |
+------------------+
| [Toggle show map]|
| Titre, date…     |
| [Draft|Published]|
| [  Enregistrer ] |
+------------------+

[ Carte OFF — mobile ]
+------------------+
| Header           |
+------------------+
| [Toggle show map]|
| Lieu (texte) …   |
| …                |
| [Draft|Published]|
| [  Enregistrer ] |
+------------------+
```

## Interactions & behaviors

### Enregistrer (clic)

1. Valider formulaire (client).  
2. Si **toggle = Publié** et **état précédent persistant était Brouillon** (ou première création en Publié) → ouvrir **modale confirmation MVP** (ne pas appeler API publish avant OK).  
3. Si **toggle = Brouillon** → PUT/POST direct sans modale publication.  
4. Si **toggle = Publié** mais **déjà publié** (édition sans changement de statut) → enregistrement direct **sans** re-modale (option : modale seulement sur *transition* draft→published).

### Modale « Publier l’événement ? » (MVP)

**OBJECT ID:** `event-modal-publish-confirm`

| Élément | Contenu |
|---------|---------|
| Titre | « Publier l’événement ? » |
| Corps | « Les membres verront cet événement sur le fil du club. » + si notifications activées : « Ils pourront recevoir une notification. » _(à brancher sur roadmap notif)_ |
| Primaire | « Publier » → confirme API |
| Secondaire | « Annuler » → ferme modale, ne change pas toggle côté UI si annulation avant save — **recommandation UX :** annuler remet le toggle sur Brouillon si l’utilisateur n’a pas encore confirmé |

**Translation keys :** `event.publishModal.title`, `.body`, `.confirm`, `.cancel`

### Carte désactivée

- Pas d’appel géocodage obligatoire ; `latitude` / `longitude` **null** en base.  
- Fiche membre / détail événement : afficher **uniquement** `locationText` + pas de bouton « Itinéraire » vers Maps _(ou bouton grisé avec tooltip « Pas de point GPS pour cet événement »)_ — à spécifier en page Event Detail (hors scope immédiat, noter en Open Questions).

### Autosave (optionnel V2)

Non requis MVP ; si ajouté plus tard, ne pas doubler la modale publish.

## Validation (client + serveur alignés)

| Champ | Règle |
|-------|--------|
| `title` | Requis, 1–120 |
| `startAt` | Requis, ISO datetime |
| `endAt` | Optionnel, > `startAt` si présent |
| `locationText` | Requis, 3–500 |
| `description` | Optionnel, ≤5000 |
| `capacity` | Optionnel, entier ≥1 |
| `showMap` | bool |
| `lat`, `lng` | Requis **si** `showMap === true` ; interdits ou null si `showMap === false` |
| `status` | `DRAFT` \| `PUBLISHED` |

Messages erreur FR (exemples) :

- `event.validation.titleRequired` — « Donnez un titre à l’événement. »  
- `event.validation.pinRequired` — « Placez le point sur la carte ou désactivez la carte pour un lieu fixe sans GPS. »

## Page States

| State | When | Appearance | Actions |
|-------|------|------------|---------|
| Default | Données chargées | Formulaire éditable | Enregistrer |
| Loading initial | Fetch événement | Skeleton champs + carte | — |
| Saving | API en cours | Bouton Enregistrer disabled + spinner | — |
| Success | 200 OK | Toast succès (sonner success 3s) | Navigation ou stay |
| Error API | 4xx/5xx | Toast erreur (persist) | Réessayer |
| Dirty leave | Retour avec changements | Dialog « Quitter sans enregistrer ? » | Quitter / Rester |
| Map error | Tuiles / clé API | Bandeau dans bloc carte + lien désactiver carte | Basculer toggle OFF |
