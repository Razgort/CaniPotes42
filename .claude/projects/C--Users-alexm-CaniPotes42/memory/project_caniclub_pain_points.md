CaniClub Connect (the existing competitor by Canicompet/FFSLC team) has major UX and functional gaps identified by the user:

1. **Poor UI/UX** — Interface quality is subpar ("pas ouf")
2. **Terrible messaging** — The built-in messaging feature is horrible
3. **Broken GPS/Map** — The map with GPS points never works properly
4. **No navigation integration** — Doesn't offer to open locations in Waze/Google Maps
5. **No direct race registration** — Still forces users to go through the FFSLC website (courses.ffslc.fr) to register for races, defeating the purpose of an integrated app

**Why:** These are the core differentiators for CaniFed — the project should solve each of these pain points.
**How to apply:** Every feature decision should be measured against these gaps. The project's value proposition is a superior UX with true FFSLC integration (not just a link to the website), working maps with navigation app handoff, and proper in-app communication.
